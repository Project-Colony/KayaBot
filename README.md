# KayaBot

KayaBot est un projet Rust visant à proposer un outil similaire à FileBot pour l'organisation et le renommage de médias.

## Structure du dépôt

- `docs/` : documentation fonctionnelle et technique.
- `tasks/` : suivi des tâches et jalons.
- `src/` : code source Rust.

## Démarrage rapide

```bash
cargo run
```

Consultez `docs/docs.md` pour les prochaines étapes de documentation et `tasks/tasks.md` pour le suivi des tâches.
